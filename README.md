# カラオケゲーム

## 1. 概要

このアプリケーションは、MP4動画ファイルから音声を抽出し、ボーカルと伴奏を分離後、ボーカルパートの音程を元にMIDIファイルを生成します。生成された伴奏音声とボーカルMIDIを使用して、Pygameベースのシンプルなカラオケゲームをプレイすることができます。プレイヤーはマイクに向かって歌い、リアルタイムで自分の音程と模範の音程を比較し、スコアを獲得します。

主な機能:
*   MP4ファイルからの音声抽出 (WAV形式)
*   音声のボーカルと伴奏への分離 (Spleeter使用)
*   ボーカル音声からのMIDIファイル生成 (Librosa & PrettyMIDI使用)
*   伴奏音声と同期した音程バーのリアルタイム表示 (Pygame使用)
*   マイク入力によるプレイヤーの音程分析とフィードバック (PyAudio & Librosa使用)
*   シンプルなリアルタイム採点機能

## 2. 主な使用ライブラリ

*   **Spleeter (v2.4.2):** Deezer社製の音源分離ライブラリ。ボーカルと伴奏の分離に使用。
*   **Librosa (v0.11.0):** 音声分析ライブラリ。ボーカル音声からの音高推定に使用。
*   **PrettyMIDI (v0.2.10):** MIDIファイル生成・操作ライブラリ。抽出した音高情報からMIDIファイルを作成。
*   **Pygame (v2.6.1):** ゲーム開発ライブラリ。UI描画、音声再生、イベント処理に使用。
*   **PyAudio (v0.2.14):** PortAudioのPythonバインディング。マイクからのリアルタイム音声入力に使用。
*   **MoviePy (v1.0.3):** 動画編集ライブラリ。MP4ファイルからの音声抽出に使用。
*   **NumPy (v1.24.3):** 数値計算ライブラリ。音声データ処理や各ライブラリの内部処理に利用。

## 3. セットアップと実行

### 3.1. 依存関係のインストール

1.  **Pythonのインストール:** Python 3.9 以上を推奨します (開発時Python 3.10)。
2.  **必要なシステムライブラリのインストール:**
    *   **PyAudioのためにPortAudioが必要です:**
        *   Debian/Ubuntu系: `sudo apt-get install libasound-dev portaudio19-dev libportaudiocpp0 python3-dev`
        *   macOS: `brew install portaudio`
        *   Windows: PortAudioはPyAudioのWheelに含まれている場合があります。
    *   **SpleeterのためにFFmpegが必要です:**
        *   Debian/Ubuntu系: `sudo apt-get install ffmpeg`
        *   macOS: `brew install ffmpeg`
        *   Windows: FFmpegをダウンロードし、PATHを通してください。
3.  **Pythonライブラリのインストール:**
    プロジェクトのルートディレクトリで以下のコマンドを実行してください。
    ```bash
    pip install -r requirements.txt
    ```

### 3.2. 音源の準備 (MP4から)

1.  ボーカルと伴奏を分離したいMP4ファイルを用意します。
2.  `audio_processor.py` スクリプトを実行して、MP4ファイルから音声データとボーカルMIDIファイルを生成します。
    *   スクリプト内の `if __name__ == '__main__':` ブロックにある `TEST_MP4_FILENAME` を、処理したいMP4ファイルの名前に変更します（スクリプトと同じディレクトリに配置する場合）。
    *   または、`test_mp4_path` 変数にMP4ファイルのフルパスを直接指定することも可能です。
    *   実行例:
        ```bash
        python audio_processor.py
        ```
3.  処理が完了すると、`outData/<MP4ファイル名(拡張子なし)>/` ディレクトリ内に以下のファイルが主に生成されます。
    *   `accompaniment.wav`: 伴奏の音声ファイル
    *   `vocals.wav`: ボーカルの音声ファイル
    *   `<MP4ファイル名(拡張子なし)>_vocals.mid`: ボーカルパートから生成されたMIDIファイル

### 3.3. ゲームの実行

1.  上記 3.2 で音源ファイルが `outData` ディレクトリに正しく準備されていることを確認してください。
2.  `game.py` スクリプトを実行します。
    *   スクリプト内の `SONG_NAME` 定数が、`outData` 内の準備した曲のフォルダ名（MP4ファイル名から拡張子を除いたもの）と一致しているか確認してください。デフォルトは "test_video" です。
    *   実行例:
        ```bash
        python game.py
        ```

### 3.4. 操作方法

ゲームウィンドウが表示されたら、以下のキーで操作できます。

*   **P:** 伴奏の再生 / 一時停止
*   **S:** 伴奏の停止 (再生位置とスコアがリセットされます)
*   **M:** マイク音程分析の ON / OFF (コンソールに出力される音程情報の表示/非表示)
*   **Q:** ゲームを終了

## 4. フォルダ構成 (主要ファイル)

```
.
├── audio_processor.py   # MP4から音源とMIDIを生成するスクリプト
├── game.py              # カラオケゲーム本体のスクリプト
├── requirements.txt     # Pythonライブラリの依存関係リスト
├── README.md            # このファイル
└── outData/             # 生成された音源ファイルとMIDIファイルが格納されるディレクトリ
    └── <曲名>/
        ├── accompaniment.wav
        ├── vocals.wav
        └── <曲名>_vocals.mid
```

## 5. 注意事項・既知の問題

*   **マイクアクセス許可:** 初めて実行する際、OSからマイクへのアクセス許可を求められる場合があります。許可してください。
*   **Spleeterモデルダウンロード:** `spleeter` を初めて使用する際、学習済みモデル（比較的大容量）が自動的にダウンロードされます。これには時間がかかることがあります。インターネット接続が必要です。
*   **音程抽出精度:** `librosa` によるボーカル音声からの音程抽出精度は、歌声の明瞭さ、声質、マイクの品質、周囲のノイズなどに影響を受けます。必ずしも正確な結果が得られるとは限りません。
*   **MIDI生成品質:** 現在のMIDI生成ロジックは基本的なものであり、複雑なメロディや細かいニュアンスの再現は限定的です。
*   **リアルタイム性:** マイク入力の音程分析はリアルタイム処理を目指していますが、PCのスペックによっては遅延が発生する可能性があります。
*   **ALSAエラー(Linux):** 環境によってはALSA関連のエラーメッセージがコンソールに出力されることがありますが、多くの場合、音声再生や録音自体には影響ありません。
*   **依存関係:** `requirements.txt` に記載のバージョンは開発時のものですが、環境によっては微調整が必要になる場合があります。特に`numpy`のバージョンは他のライブラリとの互換性に注意が必要です。
